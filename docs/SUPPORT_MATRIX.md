# Support matrix

## Current state

The project is in repository-and-contract scaffolding (milestone 1). `SvgConverter`
deliberately reports `UnsupportedFeature` for all conversions. No SVG feature is
currently supported and no pixel-fidelity claim is made.

| Area | Status |
| --- | --- |
| Public options, limits and failure categories | Contract scaffolded |
| Parsing and viewport resolution | Not implemented |
| Shapes, paths and composition | Not implemented |
| CSS, gradients, images, filters and text | Not implemented |
| PNG encoding | Not implemented |
| Chrome oracle and fixture corpus | Not implemented |

The target scope and release criteria remain in [PLAN.md](../PLAN.md).
