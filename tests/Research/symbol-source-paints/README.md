# Nonuniform symbol paints

This original fixture is dedicated to the public domain under CC0-1.0.
Its two rows separate fill and stroke; its columns use solid, linear, radial and
pattern paint. Every symbol retains the same curved source under an unequal-axis
viewBox map. The fixture protects the interaction between source reconstruction
and paint placement without repeating numerical boundaries or the API matrix.

[Capture metadata](capture.json) records three independent healthy browser
processes on each host, pinned executables and exact source/reference hashes.
The Windows and Linux captures share PNG bytes while retaining separate receipts.
