# Singular source maps: open admission gap

[Twelve authored controls](capture.json) isolate the shared cause behind the eight
remaining zero-scale candidates in the
[alias review](../release-baselines/r85-alias-review.json). All currently reject
with `UnsupportedFeature`; three fresh browser processes on each host agree on
every target. The controls are font-free; original font contexts remain separate.

Eleven controls paint nothing. A singular child inside an enclosing flood filter
still permits that parent filter to fill the image. A filter inside the singular
scope paints nothing. Geometry suppression and enclosing effect ownership must
therefore remain separate. These controls also distinguish leaf/group/use/source
placement, non-scaling strokes, masks and clips.

The [transform rendering model](https://www.w3.org/TR/css-transforms-1/#transform-function-lists)
suppresses objects and descendants under a noninvertible map. The implementation
must represent this through the existing source/scene model before lowering needs
an inverse. Removing the parser's rejection alone does not establish correct
filter bounds, resource liveness or ownership.

Closure requires direct singular-map/composition and validation mechanisms, exact
original and orthogonal native results, and representative resource/owner cleanup
coverage. Preserve finite-coordinate validation and distinct paint-server transform
rules. Promote controls to routine regressions with the implementation; do not
relax existing assertions or report this explicit admission boundary as closed.
