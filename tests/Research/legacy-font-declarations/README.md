# Dormant legacy font declarations

The [owned control](declaration.svg) supplies exaggerated SVG glyphs and bold/italic
font descriptors inside `defs`. They remain dormant in the pinned browsers and
the library. The visible text uses the explicit normal/400 TrueType host binding;
the declaration's font URI is never an acquisition source. This records the
current host-font contract, not implementation of the removed SVG 1.1 font format.

[Mechanism and prepared-document checks](../../Lokad.Svg.Tests/OpenTypeFontTests.LegacyDeclarations.cs)
protect live request identity, the required snapshot and one host acquisition.
One canonical conversion retains [independent platform references](capture.json),
each captured by three healthy processes. It borrows the existing original CC0
[small-strike program](../windows-small-strikes/README.md), without copying a font.

The [original-file review](../svgweb/legacy-font-declarations.json) checks all seven
hosted legacy documents intact, with their definitions removed, and with their
glyphs/metrics exaggerated. Source bodies and variants remain in memory. Current
supplied-program contexts and historical inline-font semantics have distinct
acceptance; transported programs do not establish support for the latter.
