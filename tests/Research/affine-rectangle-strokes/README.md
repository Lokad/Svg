# Affine rectangle-stroke controls

The [manifest](manifest.json) retains eight original CC0 cases and two MIT
controls, all exact against frozen Windows/Linux references. The additions use
the original 96×72 `userSpaceOnUse` Core input and a forward clip through fractional
affine placement, a scaled viewport and unaffected siblings. Original sources
retain CC0 notices; the [MIT license](LICENSE.txt) applies to the two additions.
Source/options/reference identities were frozen before correction.

Shared native binding preserves source coordinates, physical construction windows
and fractional coverage. Native rectangle contour order permits vertical-piece
combination. Tests protect pixels/cleanup, denial, cancellation and prepared retry.
The [support contract](../../../docs/SUPPORT_MATRIX.md#supported-svg-subset) owns
the finite geometry/font/effect boundaries.
