# Glyph recording controls

These original CC0 documents use the unchanged public
[GposMarks program](../../kerning-flags/font-pack.json).
[Capture metadata](capture.json) records three fresh healthy, profile-cleaned
browser processes per source/platform, all agreeing with the earlier observations.
Image documents have a transparent 300 × 150 viewport at DPR 1; the only native
materialization embeds the supplied program through `@font-face`.

Keep flat, root-viewBox and group-product graphs separate even when their pixels
agree. The other controls protect fill/stroke order, gradient coordinates, clips,
horizontal text paths and independent stroke-only paths. Curved and angled paths
also separate font-strike precision from shader drawing coordinates. Rendering tests use one
canonical conversion per source. Direct recording mechanisms and one prepared
contract live in [the core tests](../../../Lokad.Svg.Tests/OpenTypeFontTests.GlyphRecording.cs).
The [recording model](../glyph-recording.json) maps failures and qualification.

[Original observations](observations.json) retain the initial single captures.
[Tangent observations](tangent-observations.json) retain the earlier unresolved
curved/angled observations. The current capture manifest admits both controls
after fresh triples and the shared drawing-map correction; historical single
captures alone do not establish admission.
