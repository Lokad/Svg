# Pattern leaf clips (A1)

The [manifest](manifest.json) retains three 64×64 transparent CC0 controls: a
circle-clipped pattern rectangle, a clipped-group equivalent and a translated
leaf with a forward clip and unaffected sibling. The directory [LICENSE](LICENSE)
preserves original source bytes. Frozen Windows/Linux references are exact.

Clipped pattern leaves use ordinary rendered-leaf replay so clips bind after
definitions resolve and resources stay owned by the tile scene. Resource checks
cover denial, cancellation, cleanup and prepared retry. Object-box groups have
[separate controls](../completion-pattern-object-clips/README.md).
