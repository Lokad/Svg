# Rendered use sources

Five original CC0 sources separate forward use chains, local presentation under
different ancestors, a clipped named use, overlapping group opacity and filtered
group replay. The [manifest](capture.json) retains source/reference/browser hashes
and three agreeing healthy, profile-cleaned captures per platform. Identical
platform PNGs share storage. No existing image was replaced.

[Rendering cases](../../Lokad.Svg.VisualTests/SvgRenderedUseSourceReferenceTests.cs)
use canonical conversion individually. [Mechanisms and source ownership](../../Lokad.Svg.Tests/SvgRenderedUseSourceTests.cs)
protect ordered placement, forward declarations, empty sources, duplicate IDs,
cycles, missing targets and both standalone/shared-group owners. Parser refusal,
cancellation, cleanup and retry use the existing lifecycle helper, with sampled
allocation denial across the two source paths. One
[prepared-text contract](../../Lokad.Svg.Tests/OpenTypeFontTests.RenderedUseSources.cs)
retains text layout and one font acquisition.

Rendered and definition sources share typed use nodes. Standalone aliases share
one document-owned collection; group aliases borrow their existing source range.
Both seal before graph validation. Referenced group opacity and filters reuse
existing retained replay, without separate composition or sampling code.

[Admission evidence](../svgweb/rendered-use-sources.json) preserves the initial
original differences. The [shared recording/device correction](../svgweb/filter-recording-devices.json)
closes the complete default `juanmontoya_lingerie.svg` on both hosts; the
[current outcome ledger](../svgweb/default-outcomes.csv) retains its source identity.
