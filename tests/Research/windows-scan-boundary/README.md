# Windows fitted outlines and scan curves

The original [font recipe](font-recipe.json) builds a rectangle with a turning
counter. Its small vertical extremum distinguishes fitted quadratic points from
grid-rounded, subdivided scan leaves. No hosted outline or font program is copied.

[Capture metadata](capture.json) pins three fresh, healthy, profile-cleaned browser
processes per platform. The SVG uses one canonical conversion; direct stage and
ownership tests cover point precision, scan preparation and temporary lifetimes.
All assets are [CC0](LICENSE.txt).

[Windows alpha vectors](native-alpha.json) cover four numerical phases directly in
[mechanism tests](../../Lokad.Svg.Tests/OpenTypeFontTests.WindowsScan.cs), including
the shared preparation lifetime. The separate
[rendering test](../../Lokad.Svg.VisualTests/SvgWindowsScanBoundaryTests.cs) keeps the
native Windows/Linux images and one conversion path. Existing half-unit point and
complete native-texture tests remain unchanged apart from explicit stage selection.
