# Canonical glyph paths

The CC0 [control](control.svg) separates translucent solid, gradient and clipped
gradient fills above the native glyph-mask size bound. It borrows the shared
[Noto Sans program](../supplied-font-labels/fonts/NotoSans-Regular.ttf) under its
[OFL](../supplied-font-labels/fonts/OFL.txt). [Capture metadata](capture.json)
records three healthy, identical browser captures per platform.
