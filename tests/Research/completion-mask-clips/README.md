# Clips on vector mask content (A4)

The [manifest](manifest.json) retains four 64×64 transparent CC0 controls for
leaf/group clips in user-space/object-box mask content. The directory
[LICENSE](LICENSE) preserves original source bytes. Frozen Windows/Linux
references are exact.

Object-box clips register in the final scene owner; unclipped/scalar mask routes
keep their behavior. Alpha/luminance, transformed/object-box and resource tests
cover denial, cancellation, cleanup and prepared retry. Image children in masks
remain outside the [support boundary](../../../docs/SUPPORT_MATRIX.md#clips-masks-and-composition).
