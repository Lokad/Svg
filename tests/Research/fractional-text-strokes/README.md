# Fractional text strokes

[45 source/options records](capture.json) retain 51 original and interaction roles.
They cover supplied g/Ag strokes, exact fill/A/integer controls, width and paint
order, dashes, non-scaling widths, reflection/skew/quarter turns, opacity, filters,
masks, object clips, symbol/pattern replay, small glyphs and raster density.
Every supported actual is exact on Windows and Linux through one canonical call.
Selected API and ownership paths remain separate from this rendering collection.

Chrome 153.0.8010.52 supplied three healthy fresh-process images per actual/host.
The manifest hashes the SVGs, references and captures. Native text resolves the
serif alias to the unchanged [Noto Sans bytes](../supplied-font-labels/fonts/NotoSans-Regular.ttf)
under the [OFL license](../supplied-font-labels/fonts/OFL.txt); reproductions follow
the repository [MIT license](../../../LICENSE.txt). Assertions compare full RGBA
without tolerance. Density1.25 keeps the 32 CSS-pixel SVG and changes DPR only.

Glyph mask bounds include filter guards; the four-times sampled image excludes
those columns. Its origin, allocation, limits and filter indices share that domain.
Vertical baselines snap device X to an integer, and quarter turns retain the same
axis-aligned outline fitting as fills. Layout and shaping are unchanged.
Direct mechanisms cover strike alignment and rounding boundaries; the dimension
contract admits the real 32-sample plane and still refuses a larger Windows plane.
