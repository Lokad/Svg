# Research banks

The [probe manifest](manifest.json) records original CC0 calibration inputs and
their categorized rejections or measured rendering outcomes. Feature directories
have their own manifests and licenses, including independently sourced assets.
An inexact research render is not a supported-product baseline.

[Test collections and admission](../README.md) defines how these banks relate to
the fixture corpus. [Probe workflow](../../tools/README.md#research-probes) covers
isolation, capture, metadata and graduation. Platform references remain separate;
retain original source/options/reference bytes when promoting a useful control.

`tiger-16551.svg` retains its Openclipart creator, source hash and CC0 evidence in
the manifest. Its historical auto-image reference stays diagnostic; explicit
viewport acceptance is separately declared. Use each entry's recorded outcome
rather than treating historical rejections as a current support boundary.

[Hosted SVGWeb review](svgweb/README.md) keeps per-original metadata and outcomes
without importing the remote SVG collection. Its initial diagnostic ledger is
separate from accepted offline rendering regressions.
