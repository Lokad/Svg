# Canonical substitution dispatch

Open finding: a covered ASCII run skips a selected Latin `ccmp` substitution
unless a mark or default-ignorable character activates the canonical path.
This authored font adds one `A → V` substitution to the existing
[CC0 PlainKern program](../kerning-precedence/LICENSE.txt), leaving outlines,
metrics and instructions unchanged.

Three fresh healthy captures per role and host establish that the source `AV`
must match the literal `VV` control. The source library instead differs by 320
Windows or 330 Linux pixels; the literal control is exact on both hosts.
[capture.json](capture.json) records the program recipe, immutable source/reference
hashes and pre-correction images. These are independently frozen evidence for
the pending shared dispatch correction, not passing renderer qualification.
