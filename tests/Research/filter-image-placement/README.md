# Filter source hints and image edges

Twelve inputs retain their own Windows and Linux browser images. Nine fail before
the source-hint and image-clip corrections; three protect independent positive
paths. [Capture metadata](capture.json) records hashes and three identical, healthy
fresh-process captures per input. See the [capture procedures](../../../tools/README.md).

Authored source hints are enclosed in parameter coordinates before layer scaling.
Near-integer offsets retain their real fringes, while an authored integer avoids
inverse-scaling residue. Translated source alpha and its zero-blur alias preserve
their separate graph paths.

Image edges remain antialiased under binary clips. Only an actual antialiased clip
selects the clip-specific accumulation path. The two containing parent clips have
two different native alpha pixels; both references are retained. A reflected image
checks reversed placement, and an independent baked quadrilateral protects edge
coverage without filtered-image sampling.

The [rendering tests](../../Lokad.Svg.VisualTests/SvgFilterStageReferenceTests.cs)
use the canonical conversion path. Direct source-hint tests cover numerical
boundaries; one near-integer antialiased-clip input checks scratch refusal, cleanup,
cancellation, retry and prepared replay. The API matrix remains separate.
