# Release baselines

[0.3.0.json](0.3.0.json) records the published package and library hashes, exact
source tag, Git identities of the test/reference trees, license/support document
hashes and qualification selections. These are inherited release results, not
new measurements. Use `git show v0.3.0:path/to/file` to inspect an original file.
Reference images remain beside their existing licensed source collections.

[Polygon contour ownership](contour-ownership.md) records the shared paint-binding
storage contract and its failing-before refusal, transfer and retry witnesses.
[Leaf clip retirement](clip-retirement.md) records producer/reachability evidence
for removing the obsolete destructive intersection backend.
[Resource selection](resource-selection.md) maps R74's original acceptance inputs
to direct mechanisms, existing acquisition contracts and independent native images.
[Original text acceptance](text-acceptance.md) preserves 76 fragment and paint-return
declarations, their unequal companions and separate platform references.
[Text-path baseline painting](text-baseline-paint.md) closes the original patterned
residuals through separate layout/paint metrics, with straight-path and hanging controls.
[Text-pattern matrices](text-pattern-matrices.md) separates glyph drawing from
local paint before texture sizing and removes the integer-tile sampling shortcut.
[Shared paint stages](paint-stages.md) unifies native drawing preparation for text
gradients and patterns, including group, instance and symbol recording.
[Governed host qualification](host-api-qualification.md) maps resolver, admission,
shutdown and asynchronous output contracts to source and installed-package evidence.
